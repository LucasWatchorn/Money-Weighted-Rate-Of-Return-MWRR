Introduction

The money-weighted rate of return (MWRR), which is mathematically equivalent to the internal rate of return (IRR) in the investment setting considered here, measures an investor’s realized rate of return while accounting for both the size and timing of contributions. Although the MWRR provides a useful measure of investment performance, it generally must be computed numerically.

The approximation developed in the underlying research provides a closed-form alternative to the exact MWRR. For discrete contributions, the approximation can be interpreted as a weighted average of the annualized returns earned on individual contributions, where the weight assigned to each contribution depends on both its size and the amount of time it remains invested. The approximation is given by Equation (6),

\[ \hat{y} = \sum_{i=1}^{n} w_i \frac{R_T-R_{t_i}}{T-t_i}, \qquad w_i = \frac{c_i(T-t_i)} {\sum_{j=1}^{n}c_j(T-t_j)}. \]

The objective of this research is to investigate the accuracy and limitations of this approximation through simulation. In particular, the analysis examines how approximation error is affected by characteristics of the investment horizon, contribution pattern, and return process, with the goal of identifying conditions under which the approximation is most likely to break down.

Monte Carlo simulations are conducted under Normal, Laplace, and Student’s t return distributions to examine the robustness of the approximation under different return behavior. Exact MWRRs are computed numerically using Newton’s method and R’s uniroot function and compared with the closed-form approximation. Using the simulated results under the Normal return assumption, linear regression, quantile analysis, and logistic regression are then used to investigate the factors associated with approximation error and the likelihood of entering a high-error regime. Particular attention is given to return volatility, contribution variability, investment horizon, mean return, and measures describing the distribution of contribution weights.

Approximation Accuracy Under Alternative Return Distributions

The purpose of the simulations generated was to investigate the accuracy of the approximation proposed in Equation (6) under different assumptions on the distribution of returns. Three return-generating models were considered: Normal returns, Laplace (Double Exponential) returns, and Student’s t returns. We chose these distributions to compare the approximation under both light, and heavier-tailed return behavior. The following subsection explains how we estimate the parameters used for the various distributions.

For each distribution, the simulation generates randomized contribution vectors and return vectors over N=2,3,…,10 years. We generate contributions using the Dirichlet distribution, ensuring the total contribution is normalized, and assign zero contributions randomly to reflect irregular contributions. Given the contribution and return vectors, the script computes an approximate money-weighted return, denoted \(\hat{y}\), and compares it with numerical solution’s obtained using Newton’s method and R’s built in uniroot function.

The scripts record the approximation error for each simulated case, including absolute error, relative error, and percentage error. Other useful measures such as standard deviation, mean, min/max of the contributions and returns are recorded as well. We send all of this data (including the calculations used to prepare the approximation) to an excel sheet that orders the simulations from highest percentage error to lowest, including individual sheets each N value chosen. This allows the performance of the approximation to be compared across different time horizons, and across different assumptions about the return distribution.

Representative R Implementation:

R_cumsum<-c(0,cumsum(R))
RN<-R_cumsum[N+1]
Ri<-R_cumsum[1:N]

RTi<-(RN-Ri)/(N - t)

w<-c*(N-t)/sum(c*(N - t))

y_hat<-sum(w*RTi)
Exact<-sum(c*exp(RN-Ri))
y_newt<-y_hat
tol<-1e-10
iterations<-1000

for (k in 1:iterations){
  f_y<-sum(c*exp((N-t)*y_newt))-Exact
  f_yp<-sum(c*(N-t)*exp((N-t)*y_newt))
  
  # Stopping criteria
  if (!is.finite(f_y) || !is.finite(f_yp) || f_yp == 0){
    warning("Newton's method failed.")
    break
  }
  
  y_new<-y_newt-(f_y/f_yp)
  
  if (!is.finite(y_new)){
    warning("Newton's method produced non-finite value.")
    break
  }
  
  if (abs(y_new-y_newt)<tol){
    y_newt<-y_new
    break
  }
  
  y_newt<-y_new
}

  if (length(alpha)!=N){
    stop("Alpha must have the same length as N!")
  }

  if (is.null(n_zero)){
    if (N==1) {

    } else{

  if (n_zero<0 || n_zero>(N-1)){

  }

  if (n_zero==0){
    zero_idx<-integer(0)
    active_idx<-1:N
  } else{

    active_idx<-setdiff(1:N,zero_idx)

  } else{

Linear Regression Analysis of Approximation Error

Next, we ran a linear regression model with the objective of investigating the relationship between the absolute approximation error and the characteristics of the contribution and return processes. Using data from the simulations generated under the normal return assumption.

Taking absolute error as the response variable, we tested multiple regression models, including linear models, log-transformed models, interaction effects, nonlinear terms, and regime-based models.

The explanatory variables considered include: the investment horizon \(N\), the standard deviation of contributions and returns, \(sd_c\), \(sd_R\) respectively, the mean return \(\bar{R}\), and the number of periods with no contribution.

The objective was to identify which factors contribute most significantly to the approximation breaking down, and to determine whether the relationship between these variables and approximation error can be described by a single regression model.

We begin by testing two linear models to determine whether approximation error can be described by a linear relationship. Model 1 is given by

\[ \text{Error} = \beta_0+\beta_1N+\beta_2sd_c+\beta_3sd_R+\varepsilon. \] Model 2 is an extension of model 1, by including the mean return and number of zero contributions, and is given by

\[ \text{Error} = \beta_0+\beta_1N+\beta_2sd_c+\beta_3sd_R+\beta_4\bar{R} +\beta_5Z+\varepsilon, \] where \(Z\) denotes the number of periods in which no contribution was made.

Next, we explored the log transformation of the first initial two models to try and reduce the influence of very large absolute errors and to investigate whether or not the relationship between approximation error and the explanatory variables became more stable on the log scale.

The final regression model was fitted exclusively to observations found within the high error subset, as majority of the interesting results lie there. This model incorporates the investment horizon \(N\), contribution and return volatility \(sd_c\) and \(sd_R\) respectively, mean return \(\bar{R}\), and the number of periods with no contribution as the explanatory variables.

The model was overall statistically significant (\(F=77.66\), \(p<2.2\times10^{-16}\)), and has an adjusted \(R^2\) of 0.2112, indicating that approximately 21% of the variability in approximation error can be explained by the variables considered.

Within the explanatory variables, contribution and return volatility were the strongest predictors of approximation error. The coefficient of \(sd_c\) was negative and highly significant (\(p<2\times10^{-16}\)), while the coefficient associated with \(sd_R\) was positive, highly significant (\(p<2\times10^{-16}\)), and roughly 2 times bigger than the coefficient of \(sd_c\) in magnitude. This suggests that volatility in returns plays the most dominant role in the approximation breakdown.

The mean return and number of periods with no contribution were also statistically significant at the 5% level. Higher mean returns were associated with lower approximation error, while increasing the number of periods without any contribution made reduced the approximation error slightly. Additionally, the investment horizon \(N\) was not statistically significant (\(p=0.0889\)), indicating that once the other variables are accounted for, the length of the investment period contributes little additional explanatory power.

The results suggest that the approximation breakdown is primarily driven by the volatility of the underlying return process and by the distribution of contributions. While the approximation remains accurate throughout most simulated cases, large errors become highly likely when return volatility is high, and contribution patterns deviate from uniformity.

Additional Weight-based predictors

After identifying the high-error regime and selecting Model 10 as the most favorable linear regression model, additional explanatory variables \(sd_w\) and \(entropy_w\) were investigated, representing the volatility of weights, and relative entropy between the weights vector and a uniform distribution. Prior to fitting additional models with the newly introduced predictors, correlations among the new predictors, and \(sd_c\) were examined. The interesting results are that the standard deviation of the weights is highly correlated with the standard deviation of the contributions (\(\rho_{sd_c,sd_w}=0.9710439\)), indicating that both variables describe similar characteristics of the contribution distribution, which makes sense since the weight term is defined as \(w_i=\frac{c_i(T-t_i)}{\sum_{j=1}^{n} c_j(T-t_j)}\). Additionally, the entropy of the weights has a slightly positive correlation with the standard deviation of the weights (\(\rho_{sd_w,entropy_w}=0.130631\)), suggesting that the entropy term may capture different information regarding the structure of the contributions. Next, we fit models 11 through 13 by altering model 10 with \(sd_w\), \(entropy_w\), and both variables simultaneously. The respective model equations can be found below:

\[ \log(\text{Error}+10^{-6}) = \beta_0 +\beta_1N +\beta_2sd_c +\beta_3sd_R +\beta_4\bar{R} +\beta_5Z +\beta_6sd_w +\varepsilon. \]

\[ \log(\text{Error}+10^{-6}) = \beta_0 +\beta_1N +\beta_2sd_c +\beta_3sd_R +\beta_4\bar{R} +\beta_5Z +\beta_6\text{entropy}_w +\varepsilon \]

The introduction of the additional weight-based predictors provided further insight into the factors influencing approximation error within the high-error regime. Introducing \(sd_w\) resulted in the greatest improvement among the additional models, increasing the adjusted \(R^{2}\),while reducing the AIC relative to model 10. This suggests that the volatility in weights contains useful information regarding approximation error that was not fully captured by the original predictors used, and interestingly enough, the investment horizon \(N\) was no longer statistically significant (\(p=0.777\)). When the entropy of the weights, \(entropy_w\), was introduced as the only additional predictor, it was found to be statistically significant, but only produced modest improvement in model performance. Furthermore, when both \(sd_w\) and \(entropy_w\) were introduced as predictors simultaneously, the entropy measure was no longer statistically significant (\(p=0.2064\)), while \(sd_w\) remained highly significant (\(p<2\times10^{-16}\)). This indicates that the explanatory power of entropy is largely captured by the volatility of the weights. Interestingly enough, the coefficients for \(sd_c\) and \(sd_w\) have sign differences and both remain highly statistically significant although being highly correlated, causing concern for multicollinearity being present between the two predictors. Overall, these results suggest that the distribution of contribution weights influences approximation error primarily through their variability rather than their entropy. Although \(sd_w\) improves the model, the improvement does not alter the primary conclusions of the regression analysis. Consequently, model 10 retains as the primary regression model, with models 11 through 13 serving as supplementary analyses to investigate the effect of the additional weight-based predictors.

Investigating entropy of contributions term

Although the previous regression models identify several factors associated with approximation error, they did not directly quantify the structure of the contribution pattern. To address this, we introduce an entropy measure of contribution concentration.

Specifically, we considered the relative entropy (Kullback-Leibler divergence) between the observed contribution vector and a uniform distribution. This quantity provides a numerical measure of how far a contribution pattern deviates from an equal allocation across all periods. Small values correspond to nearly uniform contribution patterns, while larger values indicate increasing deviation from a uniform contribution.

The entropy term was calculated as follows,

\[ D(c\|u) = \sum_{i=1}^{N} c_i \log(Nc_i), \]

where u_i=1/N denotes the uniform distribution.

The relationship between relative entropy and approximation error is shown in the first plot. Although several of the largest approximation errors occur at moderate to high levels of entropy, the overall relationship is weak. Large and small errors are observed throughout much of the entropy range, and no clear monotonic pattern is present. This suggests that contribution pattern alone is insufficient to explain the approximation breakdown. While entropy appears to influence the performance of the approximation, it cannot account for the large errors observed in specific simulation cases.

The second plot compares relative entropy with the volatility of contributions. A strong, positive relationship is clear, indicating that both measures capture similar aspects of contribution patterns. As the volatility of contributions increases, the relative entropy tends to increase as well. However, the fan-shaped structure of the plot suggests that entropy contains additional information beyond simple variability. Two contribution vectors may have similar standard deviations, while exhibiting different levels of concentration across each period, allowing entropy to provide a more direct measure of deviation from a uniform contribution pattern. Additionally, no significant relationship is observed between the entropy term and return volatility. The entropy values remain widely dispersed across the range of return standard deviations, suggesting that contribution pattern and return volatility capture fundamentally different characteristics of the simulation inputs. This distinction is important as it highlights that the entropy measure is not acting as substitute for return volatility. Instead, it provides information specifically related to the structure and concentration of the contribution pattern.

These results suggest that contribution pattern plays a role in determining approximation accuracy, but it is not the primary driver of the approximation breaking down. Instead, entropy should be viewed as a supporting measure that captures concentration effects alongside the volatility and subsets identified in the previous regression analysis.

The linear regression analysis demonstrated that approximation error cannot be adequately described using a single regression model. The initial models consistently exhibited heteroscedasticity and distinct residual patterns, indicating that the relationship between the explanatory variables and approximation error varied across different subsets of the data. Applying a log-transform to the response variable improved model fit, but did not eliminate these systematic patterns. Similarly, introducing interaction terms, nonlinear effects, and regime indicators resulted in only marginal improvements, while leaving the underlying residual structure unchanged. A substantial improvement was obtained by separating the observations into low and high-error regimes. Within the high-error subset, the residual diagnostics became more stable, demonstrating that approximation error follows a more consistent relationship with the explanatory variables once the two regimes are modeled separately. The resulting regression model identified investment horizon, contribution volatility, return volatility, and mean return as the primary characteristics associated with large approximation errors. Additional weight-based predictors were then investigated to determine whether the distribution of contribution weights provided further explanatory power. While the volatility of the weights improved model performance, the entropy measure contributed little additional information once weight variability had already been accounted for. This analysis indicates that the volatility of weights is more informative than their entropy, but they do not change the primary conclusions extracted from the linear regression analysis. Overall, the linear regression analysis demonstrates that the newton approximation error performs reliably for majority of simulated observations, with its largest errors occurring only under specific combinations of return and contribution characteristics. These findings motivated a more detailed investigation of how the explanatory variables evolve across different levels of error, which is done in the following quantile analysis.

Logistic regression model

While the linear regression models identified the factors influencing the magnitude of approximation error, they do not directly identify whether a particular simulation is likely to produce a large approximation error. Consequently, a logistic regression model was built to classify observations as either low or high error approximations using the binary response variable Y, where Y=1 if we reside in the high error regime, and 0 otherwise. Observations whose approximation error fell within the largest 20% of the dataset were classified as belonging to the high error regime, while all remaining observations were classified as low error approximations. Odds Ratios and Confusion Matrix

To aid interpretation of the fitted logistic regression model, we use the estimated coefficients to calculate odds ratios, quantifying the change in the odds of an approximation being classified as a high-error observation for a one-unit increase in each explanatory variable, holding all other variables constant.

An odds ratio greater than 1 indicates that increasing the corresponding predictor increases the odds of belonging to the high-error regime, whereas an odds ratio less than 1 indicates that increasing the predictor decreases the odds of belonging to the high-error regime. Since the model contains both linear and quadratic terms in \(sd_R\), the effect of return volatility on the odds of a high-error approximation is nonlinear, meaning the overall effect depends on the current level of \(sd_R\). Consequently, the individual odds ratios associated with these terms should be interpreted together as components of the overall relationship of return volatility. Conclusion

This research investigated the accuracy and limitations of a closed-form approximation to the money-weighted rate of return (MWRR) through Monte Carlo simulation and statistical analysis. The approximation was evaluated under Normal, Laplace, and Student’s t return distributions, with exact MWRRs computed numerically to provide a benchmark for measuring approximation error.

The simulation results indicate that the approximation performs well across a large portion of the simulated investment scenarios, but its accuracy deteriorates under particular combinations of return and contribution characteristics. Regression analysis showed that approximation error could not be adequately represented by a single linear relationship across the full dataset. Separating the observations into low and high error regimes produced a more stable relationship within the high-error subset and allowed the characteristics associated with approximation breakdown to be examined more directly.

Within the high-error regime, return volatility and the distribution of contributions emerged as important factors associated with approximation error. Return volatility was consistently an important predictor, while measures related to contribution variability and the resulting contribution weights provided additional explanatory information. Weight volatility improved the regression models, whereas entropy-based measures provided comparatively limited additional explanatory power once other contribution characteristics were included.

The quantile analysis provided a complementary view of these relationships by examining how the characteristics of simulated investment scenarios changed across the distribution of approximation error. Logistic regression was then used to examine whether these characteristics could identify simulations belonging to the high-error regime. The selected model correctly identified approximately 75.6% of high-error observations, although its overall classification accuracy remained moderate. These results suggest that the factors associated with approximation breakdown can provide useful information about when the approximation is more likely to perform poorly, but they do not completely explain the occurrence or magnitude of large errors.

Overall, the analysis demonstrates that the accuracy of the MWRR approximation depends not only on the investment horizon or contribution schedule individually, but on the combined characteristics of the return process and contribution structure. The approximation remains useful across a broad range of simulated scenarios, while the statistical analysis provides greater insight into the conditions under which additional caution or numerical calculation of the exact MWRR may be warranted.
